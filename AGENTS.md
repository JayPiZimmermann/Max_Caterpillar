# Project terminology

Use “zonotope” for the translated sums of segments in the caterpillar
construction, including when the generators are linearly independent.
Preserve this user preference in future paper and documentation edits.
In paper prose, write the functions \(\sigma(x_i-x_j)\) explicitly instead
of using the unexplained shorthand “pair hinges.”
Refer to the “first hidden layer” and “second hidden layer” explicitly;
distinguish them from the input layer and output layer.

# Editing workflow

Apply requested wording improvements directly to the paper and rebuild its
PDF. Do not merely paste proposed replacement text into chat, unless the user
explicitly requests that instead.
