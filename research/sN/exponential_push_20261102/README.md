# Exponential second-hidden-layer bound: current research push

This directory contains research beyond the published checkpoint
`ffdbc2e0c61bfd708f022ad87c403113ea75dd6b`. The published unconditional
quadratic bound and conditional square-root-exponential bound remain unchanged.
The objective is an unconditional superpolynomial or exponential lower bound
for exact MAX with a quadratic first hidden layer. No such new bound is claimed
by this directory's existence.

## Live structural target

Let H(k,q) mean that every actual braid-first-layer representation of MAX_k
has a second-hidden neuron whose summed interaction graph contains q disjoint
edges. Arbitrary real coefficients, affine heads, and signed output
cancellation must be allowed. The existing conditional transfer needs this
obstruction for growing q. The first unproved useful fixed-q case is q=3.

### Cycle deletion

There is a new exact identity. Orient a graph cycle cyclically, so its linear
forms sum to zero. At every real input at least one of their ReLUs vanishes.
The alternating finite difference in all cycle terms therefore vanishes, for
any outer function and arbitrary signed coefficients. Isolating the original
term expresses it as a signed sum of terms with at least one cycle edge
deleted. Reorienting an edge only changes the linear head.

Iterating gives forest terms without introducing any new nonlinear edge.
The generic identity is Lean checked in `structural/CircuitDeletion.lean`.
The original-orientation expansion, termination, graph matching/cover theorem,
and actual-network bridge are separate obligations; consult their individual
receipts before calling the whole reduction Lean verified.

Mathematically this identifies the finite function spans generated by
matching-number-at-most-r neurons and vertex-cover-at-most-r neurons, at
the same input arity. Forests have equal maximum matching and minimum vertex
cover. The converse inclusion is immediate. This is a qualitative span
equivalence: expansion can increase the second hidden width, so it does not
transfer numerical width bounds without a separate cost argument.

### A simpler analytic tool, now Lean checked

Applying one coordinate finite difference in each of N coordinates to MAX_N
gives, up to sign, the tent function

    max(0, h - (max(x) - min(x))).

For positive h this is nonzero and has bounded support modulo the diagonal.
A difference along a non-diagonal direction is injective on functions with
such support: an invariant nonzero function would repeat along an unbounded
sequence. Consequently MAX_N cannot be a finite sum of functions each
invariant along its own non-diagonal direction, even with an affine remainder.

The actual MAX theorem is now Lean checked, with an independent semantic
audit: [NoRidgeSum.lean](ridge_annihilator/NoRidgeSum.lean) proves the result
even for completely arbitrary summand functions, each with just one
non-diagonal period. The actual affine-network bridge in
[ActualRank.lean](ridge_annihilator/ActualRank.lean) proves that, for N>=3,
some original second neuron with nonzero output coefficient has observation
rank at least N-1. Its observation consists of its linear head and the
first-row covectors multiplied by their incoming weights. Arbitrary real
biases, heads, and output skips are included.

For forest neurons this forces some term to use at least N-2 independent
edges. It does not allow arbitrary low-rank terms to be deleted from an
identity, and does not by itself give H(k,q).

## Counting target beyond the square-root exponent

For braid first hidden layers, use all vanishing tail-gradient equations,
instead of only a sparse set of isolated matching constraints. The live
general question is whether a weighted graph's chamber-gradient distribution
under a uniform vertex order has maximum atom at most exp(-c times its
matching number), uniformly over arbitrary nonzero real edge weights.

Forests and graphs with all edge weights of one sign satisfy a stronger
orientation-uniqueness statement. This yields a mathematically proved
conditional exp(cN) route for those restricted graph classes; the actual
network and probability formalizations are tracked separately. Signed cycles
prevent simply extending the same proof to arbitrary neurons. See the
counting notes and exact gradient-fiber controls.

For arbitrary first hidden rows, the previously verified Bernoulli transfer
already gives a conditional exp(c sqrt(N)) bound. An improved braid argument
does not automatically remove the non-braid contamination issue.

## Refuted shortcuts and finite evidence

* A unitwise signed-span reduction from cover-r forests to anchor-at-most-r
  or cover-at-most-(r-1) neurons is false. Independent full-support crease
  invariants give explicit counterexamples. A transformation of an entire
  already-glued network is a different, still open proposition.
* Exact finite orbit searches through 13 inputs found no matching-two
  counterexample in their declared families. Their rational certificates
  exclude those finite families only, not all real parameters.
* Configuration-dependent linear offsets occur for arbitrary first hidden
  rows. A fixed-offset probability estimate cannot be imported without a
  uniform or conditional argument.

Every reported result must retain its evidence level: mathematical proof,
finite exact certificate, Lean-checked isolated statement, integrated theorem,
or published theorem. Research leaves are not automatically imported by the
published roots.
