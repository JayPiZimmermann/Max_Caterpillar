# P4 four-free-term search: exact ray cones and closed triangle facets

**Status.** This is a certified partial exclusion, not a new width lower
bound. The fixed nine-row P4 first hidden layer still has the established
bounds `6 <= h2 <= 14`. The complete four-free-term domain has 296,861
unordered covering quadruples and 4,749,776 output-sign cases. A solver-free
independent replay verifies that 140 rational templates exclude 4,738,824
cases, leaving 10,952. One of those remaining cases has a further complete
34-node closed-facet exclusion. No conclusion is drawn about the others.

The first seven rows are the invariant features

```
σ(u), σ(v), σ(v-u), σ(s), σ(t), σ(s-t), σ(v-t),
```

and the last two rows are the positive and negative parts of the reference
coordinate. The core question allows an arbitrary linear remainder in the
seven features and four signed outer ReLUs of arbitrary real linear
combinations of them. There is no coefficient box, positive margin,
integer-weight restriction, or sampled-input assumption. Nonzero output
magnitudes are absorbed into the preactivations. Repeated coefficient flats
are allowed. Cases with fewer nonzero terms can be padded by splitting a
term; the zero-term case already fails the full mixed-difference equation.

## Existing necessary equations and the complete domain

`overnight_root9_equations.py` constructs 26 generic top-tie locality
conditions and 23 Boolean-ray annihilator conditions directly from the
actual seven first-layer rows. The latter eliminate the arbitrary linear
remainder. The existing flat atlas is independently regenerated as the
intersections of all subsets of its ten distinct relevant hyperplanes.
There are 383 flats including zero, hence 382 nonzero flats. Each flat
comes with a basis and a 25-bit locality-cover mask. A four-term candidate
must cover every locality bit. A flat is used as a closed linear space;
extra vanishing within it only enlarges the necessary domain.

The new domain verifier joins two sorted pair lists, independently of the
producer's triple loop. An additional Burnside check gives 7,116,852 ordered
covering quadruples and 1,302 ordered covering triples. There are no
covering pairs, so the unordered count is

```
(7,116,852 + 6*1,302)/24 = 296,861.
```

All sixteen signs are checked for each quadruple, including repeated flats.

## Exact convex cones for a single preactivation

On a flat of dimension d, collect the linear forms `f_j(theta)` occurring
inside absolute values in the 49 equations. They span the full dual space.
For each central-arrangement chamber, the map

```
theta -> (|f_1(theta)|,...,|f_m(theta)|)
```

is linear, and the chamber is a pointed polyhedral cone. Its extreme rays
are kernels of independent `(d-1)`-subsets of the forms. Thus every actual
absolute-value vector lies in the cone generated by all the recorded
absolute-value ray vectors. Opposite parameter rays have the same image,
so one primitive integer representative of each unoriented ray suffices.

The producer enumerated 270,850 normal subsets and obtained 13,066 rays
across all 382 flats. The independent checker does not repeat the
producer's nullspace calculation: it checks each supplied ray, determines
its annihilated normals, verifies rank `d-1`, and checks that these sets
cover every `(d-1)`-subset. In particular every independent subset has its
unique ray supplied. Full rank and primitive normalization are also
checked. This is an exact real-parameter cover, not a directional sample.

A template is a rational linear combination of the 49 equations whose
right-hand side is one. If the resulting expression is nonpositive on
every generator ray for each of the four signed blocks, it contradicts
the candidate equations. The original 131 templates came from existing
K3 certificates and individual equations; nine more were proposed by LP
and verified rationally. The independent replay recomputes every template
bit on every ray, without importing an optimizer or trusting the producer's
LP answers.

## Why the convex cone is not enough

The first exact survivor had flats `(14388,22948,23655,32316)` and signs
`(-,+,+,+)`. Its 17 rational nonnegative ray weights satisfy all 49
equations exactly; the independent checker verifies this directly. Hence
no linear inequality valid on each complete individual ray cone can
exclude this case. The adaptive sweep stopped at this witness.

The witness is not a network. In its first block, three forms satisfy
`f0+f1=f2`, while the proposed absolute values are

```
175/81, 161/81, 58/27.
```

All three triangle inequalities are strict. For three dependent real
numbers of this kind, one absolute value must equal the sum of the other
two. The witness violates thirteen such exact disjunctions.

## The missing closed-facet constraint

Suppose `c0*f0+c1*f1+c2*f2=0`, all three coefficients nonzero. Put
`v_j=|c_j|*|f_j|`. Every actual preactivation satisfies one of the three
closed equations

```
v0=v1+v2, or v1=v0+v2, or v2=v0+v1.
```

Every ray-cone generator satisfies all three nonnegative triangle slacks.
Consequently imposing one equality is exactly a face restriction: in a
nonnegative conic representation, all generators with positive slack must
have zero weight. Retain just the zero-slack rays on that branch. This
argument remains valid on all sign boundaries, including zero values and
overlapping branches. It does not infer a chamber from a numerical sign.

A bounded proof search closed the displayed survivor using eleven such
three-way branches and twenty-three rational template leaves. The separate
standard-library verifier checks each displayed circuit's signed linear
dependence, all three branches, all ray restrictions, and each rational
contradiction. It does not trust circuit enumeration, LP status, branch
selection, or a floating-point tolerance. The result excludes exactly that
single flat/sign case, for arbitrary real preactivations.
