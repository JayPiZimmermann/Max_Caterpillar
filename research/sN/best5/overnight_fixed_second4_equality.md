# Unrestricted second width four: exact equality geometry

**Live target:** exclude, or construct, an exact two-hidden-layer network for
`max5` with second hidden layer width four and arbitrary first hidden layer.
A bound of six would match the existing `(10,6)` construction. This note
proves necessary equality-case reductions; it does not improve the current
unrestricted lower bound four.

All weights are arbitrary real numbers. Biases may first be removed by the
homogeneous recession reduction, preserving both hidden widths. There is
no free skip connection in the physical network. The shallow remainders
below arise from its actual translation tails, not from a relaxed network
model asserted to be equivalent in the other direction.

## A complete three-dimensional max/min classification

Let V be a three-dimensional linear subspace of R5 containing the diagonal
vector1. Suppose `max5+min5` is linear on V. Then, after relabeling, there
are real a,b with `|a|+|b| <= 1` such that V consists exactly of

```
(t+p, t-p, t+q, t-q, t+a*p+b*q),    t,p,q real.             (1)
```

Conversely every subspace(1) with `|a|+|b| <= 1` has dimension three,
contains1, and satisfies `max5+min5=2t`.

**Proof of necessity.** Put `c=(max5+min5)/2` on V. This is a linear
functional with c(1)=1. The five centered coordinate functionals
`x_i-c(x)` vanish on1 and span the two-dimensional dual of V/R1. Their
convex hull P has even support function, hence P=-P. A two-dimensional
centrally symmetric polygon has an even number of extreme points and at
least four. Since P is generated by only five points, it has exactly four
extreme points. Choose distinct coordinate labels realizing them and
write them as p,-p,q,-q, with p,q independent. The fifth generating point
is `a*p+b*q` in their convex hull, which is equivalent to
`|a|+|b| <= 1`. The map x↦(c(x),p(x),q(x)) is an isomorphism, proving(1).
This includes a fifth point on an edge or equal to an extreme point.

**Proof of sufficiency.** For M=max(|p|,|q|),
`|a*p+b*q| <= (|a|+|b|) M <= M`. Thus the fifth coordinate changes neither
the maximum t+M nor the minimum t-M. If `|a|+|b|>1`, take p and q of
absolute value one with signs matching a and b; then the fifth coordinate
exceeds t+1, while one of the other four equals t-1. The max/min sum is
not2t. Thus the parameter condition is exact.

There are15 closed charts: five choices of the fifth label and three
pairings of the remaining four labels. Ordering each pair and the two
pairs only changes signs or exchanges a,b. A chart has annihilator
spanned by

```
L1 = x1+x2-x3-x4,
L2 = 2*x5-x1-x2-a*(x1-x2)-b*(x3-x4).                       (2)
```

The charts overlap, especially on the diamond boundary; no genericity
assumption or positive cutoff may remove those cases.

On every chart the restricted maximum is already shallow:

```
max5|V = t + max(|p|,|q|)
        = t + (|p+q|+|p-q|)/2.                            (3)
```

Consequently a further restriction to V, using only odd-linearity or
shallow representability there, cannot exclude the equality case.

## Exhaustive slope split when h2=4

The established translation-tail free-neuron bound gives at least two
zero-slope neurons at each end for N=5. The diagonal slope identity gives
at least one positive-slope neuron at each end. Thus each end has exactly
one or two nonzero slopes. This exhausts the following two cases.

### Some end has two nonzero slopes

That tail is an exact identity

```
max5 = R + d1*sigma(g1) + d2*sigma(g2),                    (4)
```

where R is homogeneous shallow with common-shift slope one, and both g_i
are homogeneous shallow and translation invariant. Define their linear
odd parts `ell_i(x)=g_i(x)-g_i(-x)`. Their common kernel contains1. On it
the two outer terms are even, so `max5+min5=R(x)-R(-x)` is linear.
The existing max/min subspace bound forces this kernel to have dimension
at most three. Since there are only two linear forms, its dimension is
at least three. Hence ell_1,ell_2 are independent, their kernel has
dimension exactly three, and it is one of(1).

Equivalently, in one of the15 charts,

```
(ell_1,ell_2)^T = C * (L1,L2)^T,   C invertible.            (5)
```

Each `g_i = ell_i/2 + e_i`, where e_i is an arbitrary even homogeneous
shallow function, hence a finite real linear combination of absolute
linear forms. No restriction to coordinate differences follows. The
classification fixes the possible odd kernel; it does not reduce the
remaining even functions to a finite first-layer dictionary.

Zero output coefficients or an identically zero free preactivation do
not create an omitted case: they would give a one-free-term version of
(4), whose odd-kernel dimension is at least four, already impossible.

### Both ends have one nonzero slope

The unique positive-end pass n has positive output coefficient and the
unique negative-end pass m has negative output coefficient. Therefore
n and m are distinct, and the other two neurons are free at both ends.
For each common free neuron define the antipodal linear form

```
b_k(x)=G_k^+(x)-G_k^-(-x)=sum_j W_kj (a_j dot x).
```

The established antipodal argument makes `max5+min5` linear on
`V=ker(b_1) intersect ker(b_2)`. Both b_k vanish on1. The same dimension
count makes them independent and V three-dimensional, so this case also
has a15-chart equality reduction(1)-(2), now for the span of the b_k.
The forms b_k need not be the odd parts of either one of the two tail
intercepts; conflating these would discard the possible shifted-tail
mechanism.

## An additional transverse reduction in the one-pass case

The normalized two-tail identities can be written

```
max5 = u+alpha-sigma(v) + sum_(i=1,2) s_i*sigma(w_i+delta_i),
max5 = -v-beta+sigma(u) + sum_(i=1,2) s_i*sigma(w_i),
```

where u,v,w_i are homogeneous shallow, alpha,beta,delta_i are linear,
`s_i in {+1,-1}`, and the w_i and delta_i are translation invariant.
Subtracting gives the global positivity identity

```
sigma(-u)+sigma(-v)
  = L + sum_i s_i*(sigma(w_i+delta_i)-sigma(w_i)) >= 0,
L=alpha+beta.                                               (6)
```

If delta_1 and delta_2 are independent, let H be their common kernel.
On H the right side is L, so L vanishes on H and u,v are nonnegative
there. Each w_i has one weak sign throughout H. Indeed choose y_i with
`delta_i(y_i)=1` and `delta_j(y_i)=0` for j≠i. At a point z∈H with w_i(z)>0,
continuity and both signs of a sufficiently small t make(6) imply
`L(y_i)=-s_i`. At a point with w_i(z)<0 they instead imply `L(y_i)=0`.
Thus both signs cannot occur. This proof does not require the other w_j
to be nonzero, since its difference in(6) is identically zero along
z+t*y_i. The identically zero restriction is also covered.

Therefore both sigma(w_i)|H are shallow, and the displayed tail identity
shows max5|H is shallow. Its odd part is linear, dim H=3, and H itself
has form(1). This provides a second equality-plane restriction, in
addition to the antipodal one. It supplies no contradiction: formula(3)
shows that shallow representability on such H is possible.

When the shifts delta_i are dependent, this transverse argument cannot
separate the two free neurons. Their activation contributions can cancel
in a common transverse direction. That case remains open; one must not
replace the rank by two or silently assume one free neuron disappears.

## Why the remaining step is genuinely transverse

Even on the four-dimensional hyperplane
`x5=(x1+x2+x3+x4)/4`, the fifth input never wins, and the maximum has the
one-free-term identity

```
max5 = max(x3,x4) + sigma(max(x1,x2)-max(x3,x4)).
```

Both inner maxima are shallow. Thus a hyperplane restriction can remove
the very fifth-input interaction needed for an exclusion. The unresolved
problem is compatibility away from the equality subspaces, with the fifth
coordinate free, arbitrary non-braid first-layer hyperplanes, and all
boundary sign patterns retained.

## A new two-free-term obstruction: constant signs on winner cones

Let `C_i={x : x_i>x_j for all j≠i}`. There is no identity

```
max5 = R+d1*sigma(g1)+d2*sigma(g2)                         (7)
```

with arbitrary homogeneous shallow R,g1,g2, provided each g_k has a fixed
weak sign on each whole C_i. The signs may differ between winner cones,
and zero restrictions are allowed. This hypothesis is not known to follow
from(7); the theorem does not assert a general K=2 exclusion.

The proof uses the established two-winner rigidity lemma: a homogeneous
shallow function agreeing with max5 on C_i and C_j equals max(x_i,x_j)
globally. To recall its reason, consolidate first-layer hyperplanes. A
wall meeting either cone must have zero coefficient. A hyperplane avoiding
both cones is necessarily their coordinate-equality wall. The remaining
linear-plus-one-hinge function is then determined by its values on the
two open cones. In particular no shallow function agrees with max5 on
three distinct winner cones.

Assign to each C_i its constant two-bit activation pattern, making either
consistent choice for a preactivation identically zero there. The four
shallow branch functions are

```
F00=R, F10=R+d1*g1, F01=R+d2*g2, F11=R+d1*g1+d2*g2,
F00+F11=F10+F01.                                          (8)
```

A branch serves at most two winner cones. Five labels in four branches
therefore have occupancy(2,1,1,1) or(2,2,1,0).

For(2,1,1,1), the repeated branch is max(x_i,x_j). Its normal derivative
has a nonzero jump on `x_i=x_j`. Every other branch agrees with a different
coordinate x_k on C_k. Since the hyperplane `x_i=x_j` meets C_k, its
consolidated shallow coefficient in that branch is zero. Taking the jump
coefficient in(8) is a contradiction.

For(2,2,1,0), relabel the singleton label as5. A sign flip of either g_k
is absorbed into the shallow remainder using `sigma(-g)=sigma(g)-g`, so
place the unused pattern at00. The two repeated branches are pair maxima
M_A and M_B on the other four labels.

If the singleton pattern is adjacent to00, say10, then F01=M_A and
F11=M_B. Thus `d1*g1=M_B-M_A`, which takes both signs on C5, contradicting
the assumed fixed activation there. The only remaining position is11.
Write `F10=M_A, F01=M_B, F11=S`; then

```
F00=M_A+M_B-S, d1*g1=S-M_B, d2*g2=S-M_A.
```

On C5, S=x5>M_A,M_B and both preactivations are nonnegative, so d1,d2
are positive. The assigned signs on the other four winner cones imply

```
min(M_A,M_B) ≤ S ≤ max(M_A,M_B)                            (9)
```

whenever x5 is below the largest of those four coordinates. Continuity
covers their tie boundaries.

There is no such shallow S. The shallow function S-x5 vanishes on C5.
Every surviving first-layer hyperplane must avoid C5. Up to orientation
and positive rescaling its equation is
`alpha1*x1+...+alpha4*x4-x5=0`, where alpha_i≥0 and sum alpha_i=1.
Indeed a nonzero common-shift slope would make the hyperplane meet C5;
with zero slope, all coefficients other than the fifth must have the same
weak sign. Orienting all these functions to be negative on C5 leaves no
linear remainder. Consequently

```
S=x5+sum_j c_j*sigma(alpha_j dot (x1,x2,x3,x4)-x5).
```

For fixed first four coordinates and sufficiently negative x5 every term
is active. Boundedness in(9) forces sum c_j=1, and S becomes a linear
function L of the first four coordinates, bounded between M_A and M_B
for all inputs. At each negative coordinate vector -e_i both pair maxima
are zero, so L(e_i)=0 for all four i. At(1,1,1,1) both pair maxima are one,
a contradiction. This completes the proof of the conditional theorem.

**Consequence for the unrestricted search.** In the two-nonzero-slope
case above, any hypothetical width-four network must have a free tail
preactivation taking both signs inside at least one single-winner cone.
The unresolved mechanism is cancellation or refolding of such interior
activation changes. A claim that they cannot occur would require a new
argument; the convexity of max5 alone has not established it here.

The other proof agent independently checked both occupancy cases, weak
zeros, the wall-coefficient argument, bit flips, the convex-combination
normal form, and the negative-x5 limit. The adjacent Lean leaf verifies
only two elementary ingredients: the impossibility of the linear selector
in(9), and the diamond bound used in(1). It does not formalize the full
winner-cone theorem or a new network lower bound.
