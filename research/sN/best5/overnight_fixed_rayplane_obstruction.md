# Why the sixteen ray-plane tests alone cannot exclude all widths

This is an exact obstruction to a proposed proof route, not a network
construction. A finite sum of outer ReLUs can match the target on every
quadrant generated by one group ray from each group, while failing on
the interiors of the full product cones. Therefore an all-width lower
bound must use more than those sixteen ray-plane curvature measures.

Write `(a,b,p)=(sigma(u),sigma(v),sigma(u-v))` and
`(c,d,q)=(sigma(s),sigma(t),sigma(s-t))`. The group maxima are `M1,M2`.
For every `T>=0`, the three group-face cases give the exact identity

```
sigma(M1-T) = sigma(b+p-T) + sigma(a-b-T) - sigma(p-T).
```

Put `L=(b+p,a-b,p)`, `K=(d+q,c-d,q)`, and `epsilon=(1,1,-1)`. Then

```
H = sum_(i,j) epsilon_i epsilon_j sigma(L_i-K_j),
max(M1,M2) = c + H + min(sigma(b-a),sigma(d-c)).             (1)
```

For a derivation, set `h(t)=sum_j epsilon_j sigma(t-K_j)`.
For `t>=0`, the one-group identity gives
`h(t)=sigma(t-M2)+sigma(d-c)`. For `t<0`, because `d+q,q>=0`,
`h(t)=sigma(t+d-c)`. If `a>=b`, all L_i are nonnegative and (1)
follows with zero residual. If `a<b`, the first group is on its face
`p=0`; use `L=(b,a-b,0)` and the two formulas for h. The residual is
`sigma(d-c)-sigma(a-b+d-c)=min(b-a,sigma(d-c))`.

It remains to imitate the residual on ray planes. Define

```
X=b-a, Y=d-c, h1=b+p-a>=0, h2=d+q-c>=0,
g_rs=X-Y+r*p+s*q,
P_rs = -sigma(g_rs) + sigma(g_rs-h1)
       +sigma(g_rs+h2) - sigma(g_rs-h1+h2).
```

For `r<=0,s>=0`:

* P_rs is zero if either group lies on the face `a=b+p` (respectively
  `c=d+q`), since then h1 or h2 is zero.
* On the product of the faces `p=q=0`, it is `min(X,Y)`.
* On either mixed product of `p=0` with `d=0`, or `b=0` with `q=0`,
  it is zero. This follows by checking the endpoints of the two
  intervals whose overlap length is P_rs.

The only remaining product is `b=d=0`. Each group has two extreme rays:
`a=p` or `a=0`, and `c=q` or `c=0`. If `a=p` or `c=q`, P_rs is zero.
For `a=c=0`, it simplifies to

```
P_rs = -sigma(rp+sq)+sigma((r-1)p+sq)
       +sigma(rp+(s+1)q)-sigma((r-1)p+(s+1)q).
```

Summing this formula over `r in {0,-1}`, `s in {0,1}` telescopes, and
positive homogeneity gives `2*min(p,q)=2*P_00`. Consequently

```
P_(-1,0)+P_(0,1)+P_(-1,1)-P_(0,0)=0       when a=c=0.
```

Thus the finite shallow expression

```
Rhat = (P_(-1,0)+P_(0,1)+P_(-1,1)-P_(0,0))/2
```

equals `min(sigma(b-a),sigma(d-c))` on all sixteen quadrants generated
by one extreme ray from each group. Combining with (1), `c+H+Rhat`
matches the full target on all those quadrants. Every displayed
preactivation is linear in the six first-layer features.

This does not assert equality in the interiors of the product cones.
The reopening condition for a curvature-propagation proof is to use
the full four-dimensional cone restrictions, retaining the dependence
on a and c, rather than only their extreme-ray quadrants.
